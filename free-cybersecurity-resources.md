# The Big List: Free Cybersecurity Resources by Domain

Hi, I'm Eva. This is the full library. Every resource on this page is free to start.

If you are brand new, don't start here. Start with my [2027 Roadmap](https://github.com/evabenn/cybersecurity-resources/blob/main/cybersecurity-roadmap-2027.md), pick one resource per step, and come back when you want more.

**How "free" works here:**
- Every resource has a free version that is enough to learn from
- Most ask you to create a free account
- Some sell paid upgrades, labs, or exams. You don't need them to learn
- Self-hosted labs are free to run on your own computer. A few need an AI API key, which can cost money

Big thanks to [Andrew Bellini](https://www.digitalandrew.io), whose free training is all over the AI and IoT sections, and to the [Arcanum AI Security Resource Hub](https://arcanum-sec.github.io/ai-sec-resources/), where many of the AI labs on this page come from.
